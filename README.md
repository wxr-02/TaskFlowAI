# TaskFlow AI

> 一个会**记住你的操作习惯**的 Android 智能任务助手 —— 用一句自然语言,让大模型调起系统能力完成你的任务。

```
> 设个明天早上7点的闹钟
🤖 好的,已为你设置 07:00 的闹钟(起床)

> 先给妈妈发短信说晚点回家,再查一下北京天气
🤖 短信需要你确认… → [允许] → ✅ 已发送 → ✅ 北京:晴,-2~8°C
```

TaskFlow AI 不是"套壳聊天",而是一套完整的 **LLM Agent 端侧落地工程**:大模型负责规划(Natural Language → 工具调用序列),应用负责**安全执行**(权限预检 / 用户确认 / 中断恢复),并在每次成功中学习,越用越懂你。

---

## ✨ 特性一览

| 能力 | 说明 |
|---|---|
| 🔧 **Function Calling 工具系统** | 闹钟(**可设置 / 可取消 / 可查询 / 到点全屏响铃**)/ **打开其他应用(按中文名智能匹配,真机实测唤起华为天气)** / 日历 / 短信 / **实时天气(Open-Meteo 真实数据,无需 Key)**;解耦的 `Tool` 契约 + Hilt 多绑定注册,新增工具 = 1 个类 + 1 行绑定 |
| ⏰ **可管理的闹钟** | 闹钟由应用自持注册(`AlarmManager.setAlarmClock`,系统级),因此支持"关掉所有闹钟 / 按时间 / 按标签取消";到点全屏响铃(锁屏可亮屏)+ 循环闹铃 + 一键关闭 |
| 💬 **真实问答 + Agent 闭环** | 键盘/语音输入任意问题 → 大模型真实回答;需要工具的任务执行完后,**工具结果回灌大模型生成自然语言总结**(如"北京今天晴,17.4°C,适合出门"),原始数据不再裸奔 |
| 🛡️ **人在回路(human-in-the-loop)** | 敏感操作(发短信)先弹确认;系统权限不足时优雅挂起,授权后从断点恢复,**绝不崩溃** |
| 🔄 **响应式任务引擎** | Room 持久化状态机 + WorkManager 后台执行;进程被杀也不丢进度(实测通过) |
| 🧠 **RAG 个性化记忆** | 成功的任务自动向量化入库;规划前检索相似历史(Few-Shot)注入提示词,重复指令自动沿用参数 |
| 🎨 **MVI + Compose** | 单向数据流(State/Intent/Effect 严格分离);Crossfade / AnimatedVisibility / 脉冲动画全程状态驱动 |
| 🎙️ **语音交互(双引擎)** | 按住麦克风说话(脉冲动画),松开自动识别、填入并发送;系统识别器不可用时**自动切换到 Vosk 离线引擎**(首次自动下载 42MB 中文模型,之后完全离线)—— 华为等锁死系统识别服务的设备也能用 |
| ⚙️ **运行时配置** | DataStore 持久化;设置页切换 DeepSeek / Qwen / 自定义 Base URL,API Key 密码态显示 |
| 🧯 **全局防呆** | 网络异常 → 友好提示 + "去设置"引导;API Key 未配置 → 禁止发送并引导配置 |


**一次任务的生命周期(中断与恢复)**:

```
提交指令 → LLM 规划 tool_calls → 落库 Task+Steps(PENDING)
  → Worker 顺序执行: step RUNNING → Success? 继续
        ├─ RequiresUserConfirmation → step WAITING_USER + task PAUSED ▸ Worker 结束
        │      用户点[允许] → 持久化 confirmed → 重新入队 → 带确认重放
        ├─ RequiresPermission → step WAITING_USER + task PAUSED ▸ Worker 结束
        │      用户系统授权 → 重新入队 → 重放
        └─ 全部步骤 SUCCESS → task SUCCESS
              ├─ 后台向量化写入知识库(学习闭环)
              └─ 工具结果回灌 LLM → 生成自然语言总结写回任务(Agent 闭环)
```

## 🔑 API 配置指南

设置页支持三种组合,任选其一:

### 方案 A:DeepSeek(推荐起步)

| 项 | 值 |
|---|---|
| 服务商 | `DeepSeek(对话)` |
| API Key | 在 [platform.deepseek.com](https://platform.deepseek.com) 创建 |
| Base URL | 自动填入 `https://api.deepseek.com/` |

> ⚠️ DeepSeek **没有 embeddings 接口**,RAG 学习会自动回退到**本地 n-gram 向量**(离线可用,适合近重复指令;指代式检索请用方案 B)。

### 方案 B:Qwen 通义千问(完整 RAG 体验)

| 项 | 值 |
|---|---|
| 服务商 | `Qwen 通义千问(对话 + 向量)` |
| API Key | 阿里云百炼 [bailian.console.aliyun.com](https://bailian.console.aliyun.com) 创建 |
| Base URL | 自动填入 `https://dashscope.aliyuncs.com/compatible-mode/v1/` |

> ✅ 对话 + 真实语义向量(`text-embedding-v3`),支持"和昨天一样,晚安"这类**指代式**检索。

### 方案 C:任意 OpenAI 兼容服务

选择任一服务商后,把 **Base URL** 改成你的自建服务地址(如 One-API / vLLM / Ollama 网关),保存即生效 —— 网络层在**请求时**读取配置,无需重启。

### 1️⃣ 两种输入方式

| 方式 | 操作 | 说明 |
|---|---|---|
| ⌨️ 键盘 | 输入框打字 → 点 ➤ 发送 | 常规方式;提交失败时输入框会**保留内容**,方便修改重试 |
| 🎙️ 语音 | **按住麦克风图标说话,松开** | 松开后自动识别 → 自动填入 → **自动发送**,全流程无需再点按钮 |

语音输入细节:

- 首次使用会请求**录音权限**;
- 双引擎自动选择:优先系统语音识别;设备锁死了系统识别器(如华为 EMUI)时**自动切换到 Vosk 离线引擎**——首次需联网下载一次 42MB 中文模型,之后完全离线可用;
- 松开后稍等片刻(识别 + 联网规划需要一点时间),对应的任务卡片会自动出现。

### 2️⃣ 七类系统能力(能对它说什么)

**💬 直接问答(不需要任何工具)**
> "用通俗的话解释一下什么是协程" / "帮我写一段生日祝福语"

→ 大模型直接回答,详情页显示 💬 模型回答。

**🌤️ 实时天气(Open-Meteo 真实数据,无需 Key)**
> "北京今天天气怎么样" / "上海明天天气"

→ 查询真实气象数据,再由模型总结成自然语言(如"北京今天晴,17.4°C,适合出门")。

**⏰ 闹钟三件套(应用自持注册,可设置 / 可查询 / 可取消)**
> 设置:"设个明早7点的闹钟" / "15分钟后提醒我喝水"
> 查询:"我有哪些闹钟" / "我设了几个闹钟"
> 取消:"关掉所有闹钟" / "取消7点的闹钟" / "取消喝水的闹钟"

→ 到点由 TaskFlow **全屏响铃**(锁屏也会亮屏),点"关闭闹钟"即止。
⚠️ 边界:系统时钟应用**不会显示**第三方闹钟(安卓平台限制),所以"我设了哪些闹钟"要问 TaskFlow 自己,而不是打开系统时钟应用看。

**📱 打开其他应用(中文名智能匹配)**
> "打开天气" / "打开微信" / "打开相机" / "打开设置"

→ 按中文名模糊匹配已安装的启动器应用并唤起("打开天气APP"里的"APP"字样会被自动忽略);说不到的应用会列出相近候选。

**📅 日历日程**
> "明天下午3点加个日程,名字叫小组评审"

→ 直接写入系统日历(需授权日历权限;拒绝授权也不影响其他功能)。

**✉️ 短信(双闸保护)**
> "给 138xxxx1234 发短信说晚点回家"

→ 执行前有两道闸:①**弹确认**("即将向 XX 发送短信…是否允许");②系统短信权限。任一道没过,任务挂起、绝不偷偷发送。建议直接说完整手机号,确保准确送达。

**🧩 多步任务(一句话拆成步骤条)**
> "先给妈妈发短信说晚点回家,再设个明早7点的闹钟"

→ 模型自动拆解为多个工具调用,详情页以**步骤条**呈现,逐步执行。

### 3️⃣ 任务状态与详情页

任务有五种状态(卡片右上角徽章):

| 徽章 | 含义 |
|---|---|
| 待执行 | 已规划完成,排队等执行 |
| 执行中 | 正在执行某个步骤 |
| 已暂停 | 遇到"需要确认 / 需要授权",等你处理 |
| 成功 | 全部步骤完成(自动附 💬 模型总结) |
| 失败 | 某步失败,卡片显示 ⚠️ 失败信息(绝不吞错) |

点任意卡片进入**任务详情页**,看到完整步骤条:每一步用的工具、参数、执行结果一目了然。遇到"已暂停"时,对应步骤卡片会展开 **允许 / 拒绝** 按钮:

- **确认类**(如发短信):点"允许"= 同意执行这一次;确认状态会被持久化,同一步骤不会反复问你;
- **权限类**(日历 / 短信 / 精确闹钟):点"允许"会拉起系统授权弹窗或跳转系统设置页;授权完返回,任务**自动从断点恢复**,不需要重新下发指令。

### 4️⃣ 任务管理

- **左划删除**:向左拖动任务卡片(跟手),右侧露出红色「删除」按钮,点击即删(带移除动画);
- 删除只清任务列表,知识库里已学到的记忆不受影响(要清理请去设置页)。

### 5️⃣ 设置页(右上角 ⚙️)

- **服务商 / API Key / Base URL**:随时切换,保存即生效(网络层在请求时读取配置,无需重启);
- **知识库管理**:显示当前已学习的记忆条数;「清除记忆」一键重置(带二次确认)。

```bash
# 预填输入框(不自动发送),免去手动打字
adb shell am start -n com.example.taskflowai/.MainActivity --es prefill "打开天气"
```

### 7️⃣ 使用小贴士(让它越来越顺手)

- **越用越懂你**:同一条指令说到第 3 次,规划器会自动检索前几次的成功记录作为参考(RAG Few-Shot),参数风格会自动沿袭;
- **一句话说完多个动作**:"先…再…"会自动拆成步骤,比分开下两条指令更省事;
- **打开应用说中文名就行**:多余的"APP / 应用 / 软件"字样会被自动忽略;
- **闹钟带标签更省心**:"设个明早6点半的闹钟,标签写晨跑" → 之后"取消晨跑的闹钟"就能精确命中;
- **失败不丢内容**:提交失败时输入框里的话还在,改一改直接重试。

## 🧠 如何用 RAG 训练你的习惯

TaskFlow 的学习闭环完全自动,你只需要**正常使用**:

1. **完成任务即学习**:任何"全部步骤成功"的任务,会把「指令 + 工具序列 + 向量」写入本地知识库;失败、取消、挂起的任务**绝不入库**(防污染)。
2. **重复即强化**:当你第 3 次说"设个明天早上 N 点的闹钟",规划器会自动检索到前两次的成功记录(相似度 ≥ 0.75 取 Top 3),把它们作为 Few-Shot 示例注入提示词:
   ```
   User: 设个明天早上7点的闹钟 -> Assistant: 调用了 set_alarm({"time": "07:00", "label": "起床"})
   ```
   —— 大模型据此沿用它学到的参数风格与工具选择。
3. **查看与清理**:设置页可见当前知识条数;「清除记忆」一键重启学习(带二次确认)。
4. **提示词防爆**:历史注入有 3 层 Token 防御(最多 3 条 → 单条限长 → 总量 2000 字符预算,超限显式标注"已省略"),不会把请求顶爆模型的上下文上限。

**实测效果**(采样自开发日志):

```
submit  #2 «设个明天早上7点的闹钟»   → retrieve 0 hits   → 任务成功 → learned ✔
submit  #3 «设个明天早上8点的闹钟»   → retrieve 1 hit(0.836)→ Few-Shot 注入 → 任务成功 → learned ✔
submit  #4 «设个明天早上9点的闹钟»   → retrieve 2 hits     → 模型沿用参数风格 → 任务成功 → learned ✔
submit  #5 «给妈妈发短信说晚点回家»  → 用户取消 → 任务失败 → 未入库(0 污染)✔
```

## ⚠️ 已知限制

- **华为 EMUI 短信扣费保护**:系统会在发送短信时弹出身份验证(应用侧已做"确认+权限"双闸,此为系统级额外保护);
- **部分厂商锁死系统语音服务**(如华为 EMUI 的 `FakeRecognitionService` 禁止三方绑定):已由 **Vosk 离线引擎自动兜底**,无需任何处理;
- **DeepSeek 无 embeddings**:见"API 配置指南"方案 A 的说明;
- **本地 n-gram 向量**:仅按字面相似度匹配,同义改写/指代需切换 Qwen 真语义向量;
- **闹钟管理边界**:助手只能管理**由 TaskFlow 设置的闹钟**(自持注册);系统时钟应用里手动设置的闹钟任何第三方应用都无法删除(安卓平台限制);API 31+ 需授权精确闹钟(SCHEDULE_EXACT_ALARM,详情页会引导),API 33+ 需通知权限;
- 天气数据来自 Open-Meteo 免费接口(无需 Key);若网络不可达会如实报错,不会回退到假数据;
- APK 体积:包含 Vosk 各 ABI 的 native 库,体积较大(开发版约 60MB+);发布版可通过 ABI 过滤裁剪。
